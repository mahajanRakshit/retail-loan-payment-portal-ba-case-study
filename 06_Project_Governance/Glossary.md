# Glossary

| Term | Meaning |
|---|---|
| BA | Business Analyst |
| BRD | Business Requirements Document |
| FRD | Functional Requirements Document |
| DFD | Data Flow Diagram |
| AS-IS | Current-state process |
| TO-BE | Proposed future-state process |
| UAT | User Acceptance Testing |
| RTM | Requirements Traceability Matrix |
| EMI | Equated Monthly Instalment |
| PSP | Payment Service Provider |
| Acceptance Criteria | Conditions that a story or requirement must satisfy |
| Epic | A larger body of work that can be split into stories |
| Sprint | A fixed-length Agile delivery cycle |
| Preliminary Eligibility | Indicative result, not final credit approval |
