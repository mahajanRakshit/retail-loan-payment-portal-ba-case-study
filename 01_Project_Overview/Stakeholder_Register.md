# Stakeholder Register

| Stakeholder | Needs / concerns | BA engagement approach |
|---|---|---|
| Product Owner | Business value, priorities, scope | Discovery workshop, backlog review |
| Branch Operations | Existing onboarding steps and bottlenecks | Process walkthrough, interview |
| Loan Operations | Required documents and review statuses | Requirement workshop |
| Customer Support | Common customer complaints and exceptions | Interview, issue analysis |
| Customers | Simple application and repayment journey | Persona assumptions, usability feedback |
| Development Team | Clear functional rules and dependencies | Refinement, Q&A |
| QA / UAT | Testable requirements and expected outcomes | Acceptance criteria review |
| Compliance / Risk | Privacy, consent, eligibility wording, auditability | Review checkpoints |
