# Sample Agile Sprint Plan

Illustrative two-week sprints for a learning simulation.

| Sprint | Goal | Candidate stories | Demo outcome |
|---|---|---|---|
| Sprint 1 | Customer onboarding foundation | US-01, US-02 | Profile and checklist journey |
| Sprint 2 | Application submission and tracking | US-03, US-04, US-05 | Indicative check, submission, tracking |
| Sprint 3 | Repayment visibility | US-06, US-07, US-08 | EMI schedule, payment status, history |
| Sprint 4 | Operations workflow and hardening | US-09, NFR validation | Operations status updates and test review |

## Sample Scrum ceremonies
- Sprint Planning: agree sprint goal and selected backlog items.
- Daily Scrum: discuss progress, next work and blockers.
- Backlog Refinement: clarify requirements, dependencies and acceptance criteria.
- Sprint Review: demonstrate completed increment and collect feedback.
- Retrospective: identify one improvement for the next sprint.

## Jira setup suggestion
Create a Jira project named `RLPP`. Create Epics: Onboarding, Loan Application, Application Tracking, EMI Payments, Operations. Add each US item as a Story and add acceptance criteria in the description. Use statuses: To Do, In Progress, In Review, QA, Done. These are suggested setup steps; this repository itself is not connected to a live Jira workspace.
